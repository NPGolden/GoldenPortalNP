# Customer app — store builds (Capacitor 6), same procedure as the Service Engineer app (GAS-2026-PORTAL-APP-002 §6)
App id `gr.goldenas.customer`, name "Golden A/S Portal" (SE app: gr.goldenas.service, PM app: gr.goldenas.pm). Steps: `npm i` → `node prepare-web.js` → `npx esbuild www/native-bridge.js --bundle --format=esm --outfile=www/native-bridge.js --allow-overwrite` → `npx cap add ios` / `npx cap add android` (first time) → `npx cap sync` → Xcode (Team, Push Notifications, Associated Domains applinks:goldensas.com) / Android Studio (google-services.json, signing key). Universal links: `/.well-known/apple-app-site-association` and `assetlinks.json` on goldensas.com so links in e-mails open the app when installed and the PWA otherwise. Store listing: EN/EL/IT texts, 6 screenshots per platform (docs-R68/shot-*.png as a start), privacy policy URL, support e-mail, reviewer demo account = the demo customer of install/seed_demo.sql. Release train: TestFlight / Play internal track for the pilot; the app refuses builds below the minimum version set in Settings › Login history › Mobile apps › Customer app (HTTP 426).
