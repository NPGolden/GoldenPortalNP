# Georgian (ka) — rules and term list for the translation batches (GAS-CP-R97-268)

**Rules.** Every exported id appears in the output; a text that stays the same (code, abbreviation, brand) is written unchanged. Keep `{placeholders}`, tags and pseudo-tags (`<project>`, `<branch series>`, `<variant>` …), curly quotes, literal `\n` and `\\n` exactly as exported. Translate quoted UI labels with „…“; keep Excel column headers, sheet names, field names, file names, paths and status codes in English. Bilingual English / Greek form labels become Georgian / English. Greek and Italian legal terms stay as they are (ΕΡΓΑΝΗ, ΑΦΜ, AMKA, UNILAV, TFR …). Roles: CEO stays CEO; General Manager = გენერალური მენეჯერი; HR stays HR; PM stays PM.
